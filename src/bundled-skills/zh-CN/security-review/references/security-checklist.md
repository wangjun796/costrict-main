# 安全清单

将每个类别应用于计划。标记：是（已解决）、否（必须先修复）、不适用（不适用于此任务）。

## 1. 身份验证

- [ ] 每个特权操作都需要已验证的身份
- [ ] 任何地方都不存在默认或硬编码的凭证
- [ ] 密码存储使用 bcrypt/scrypt/argon2 加每用户盐值
- [ ] 在适用的情况下支持多因素认证
- [ ] 会话令牌是密码学随机的，长度足够（>=128 位）
- [ ] 实现了会话过期和撤销
- [ ] 认证失败使用恒定时间比较（无计时侧信道）
- [ ] 重复失败后实施锁定或速率限制

## 2. 授权与访问控制

- [ ] 默认拒绝：除非明确授予，否则访问被阻止
- [ ] 每个请求都在服务器端检查授权（不仅仅是 UI 隐藏）
- [ ] 角色/权限模型使用最小权限
- [ ] 无 IDOR：对象访问针对当前用户的权限进行验证
- [ ] 管理功能分离并通过额外控制保护
- [ ] API 密钥和服务账户限定为最小所需权限
- [ ] 无通过参数篡改或强制浏览的权限提升路径

## 3. 输入验证

- [ ] 所有外部输入在信任边界处验证
- [ ] 优先使用允许列表验证而非拒绝列表
- [ ] 对每个字段强制执行类型、长度、范围和格式
- [ ] 文件上传验证：类型、大小、内容（魔术字节，不仅仅是扩展名）
- [ ] 文件上传存储在 webroot 之外，使用随机名称
- [ ] SQL、Shell 命令、OS 调用、LDAP、XML 或日志条目中不使用原始用户输入
- [ ] 所有数据库访问使用参数化查询或 ORM
- [ ] 不使用 eval()、exec() 或带有用户控制输入的动态代码执行

## 4. 输出编码

- [ ] HTML 输出：上下文感知编码（元素、属性、JS、CSS、URL 上下文）
- [ ] SQL 输出：仅使用参数化查询
- [ ] Shell 输出：不使用字符串插值；使用带数组参数的子进程
- [ ] 日志输出：结构化日志，日志消息中不含原始用户输入
- [ ] API 响应：正确设置 Content-Type 头，不反射原始输入

## 5. 密码学

- [ ] 所有网络通信使用 TLS 1.2+
- [ ] 静态敏感数据使用 AES-256-GCM 或同等算法加密
- [ ] 加密密钥通过密钥存储管理，绝不在源代码中
- [ ] 不实现自定义加密——仅使用经过验证的库
- [ ] 随机值使用 CSPRNG（如 secrets 模块、/dev/urandom）
- [ ] 启用证书验证，不禁用 TLS 验证
- [ ] JWT：算法固定（无 "alg:none"），短过期时间，服务器端签名

## 6. 密钥管理

- [ ] 源代码、提交到 VCS 的配置文件或日志中不含密钥
- [ ] 密钥从环境变量或专用密钥存储加载
- [ ] 密钥不出现在 URL、查询字符串或错误消息中
- [ ] 密钥可在不更改代码的情况下轮换
- [ ] .gitignore / .dockerignore 排除所有含密钥的文件
- [ ] CI/CD 密钥在日志中脱敏

## 7. 错误处理与日志

- [ ] 错误时拒绝访问（失败时拒绝，而非授予）
- [ ] 面向用户的错误是通用的，无堆栈跟踪或内部细节
- [ ] 详细错误仅在服务器端记录
- [ ] 记录安全事件：认证成功/失败、授权拒绝、输入验证失败、管理操作
- [ ] 日志中绝不包含：密码、令牌、PII、信用卡号、会话 ID
- [ ] 日志完整性受保护（仅追加，发送到中央存储）
- [ ] 为异常模式配置告警

## 8. 数据保护与隐私

- [ ] 仅收集最小必要数据
- [ ] PII 已识别和分类
- [ ] 定义并执行数据保留策略
- [ ] 用户数据可按请求删除（被遗忘权）
- [ ] 敏感数据在日志、分析和非生产环境中脱敏
- [ ] 静态数据加密，备份加密
- [ ] 考虑跨境数据传输要求

## 9. 网络与基础设施

- [ ] 除非必要，服务不公开暴露
- [ ] 信任区域之间的网络分段
- [ ] 防火墙规则默认拒绝，最小开放端口
- [ ] 数据库不能直接从互联网访问
- [ ] 内部服务间通信经过认证（mTLS、服务令牌）
- [ ] 审查 DNS、TLS 证书和云 IAM

## 10. 依赖与供应链

- [ ] 依赖固定到特定版本（存在锁文件）
- [ ] 依赖树中无已知严重/高危 CVE
- [ ] 最小依赖数量；每个都有正当理由
- [ ] 依赖来自官方注册表
- [ ] 锁文件提交到版本控制
- [ ] CI/CD 管道中的自动化漏洞扫描

## 11. 部署与配置

- [ ] 生产中禁用调试模式
- [ ] 删除默认账户和示例数据
- [ ] 设置安全头：CSP、HSTS、X-Content-Type-Options、X-Frame-Options
- [ ] CORS 策略限制性，非通配符
- [ ] 容器镜像最小化（distroless/alpine），非 root 用户
- [ ] 基础设施即代码审查配置错误
- [ ] 回滚程序已记录并测试

## 12. 可用性与韧性

- [ ] 所有公共端点的速率限制
- [ ] 强制执行请求大小限制
- [ ] 所有外部调用设置超时
- [ ] 下游依赖的熔断器
- [ ] 负载下的优雅降级
- [ ] 识别并缓解资源耗尽向量（CPU、内存、磁盘、文件描述符、连接）
